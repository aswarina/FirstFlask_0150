# FirstFlask_0150

## Deskripsi

Project ini dibuat untuk memenuhi tugas First Project Flask. Pada project ini membuat aplikasi sederhana menggunakan Flask untuk memasukkan nama melalui form. Setelah tombol Kirim ditekan, nama yang dimasukkan akan diproses dan ditampilkan kembali pada halaman.

## Fitur

- Menampilkan halaman utama.
- Memasukkan nama melalui form.
- Mengirim data menggunakan method POST.
- Menampilkan hasil nama yang sudah dimasukkan.
- Menampilkan pesan jika nama belum diisi.
- Memiliki route tambahan About, User, dan Post.

## Teknologi

- Python
- Flask
- HTML
- CSS

## Cara Menjalankan

1. Buka project di Visual Studio Code.
2. Pastikan Flask sudah terpasang.
3. Buka terminal dan jalankan:

   `python app.py`

4. Buka browser melalui alamat `http://127.0.0.1:5000`.
5. Masukkan nama dan tekan tombol Kirim untuk melihat hasilnya.
